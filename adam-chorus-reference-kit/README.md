# Adam — Gnostic Music Video Chorus Reference Kit

This folder is a visual continuity kit for a 16:9 cinematic music-video sequence.

## Start here
1. Open **ADAM_REFERENCE_SHEET.jpg** and inspect all six labeled reference sections.
2. Read **GROK_INSTRUCTIONS.txt** in full.
3. Create the chorus sequence one 16:9 image at a time, checking continuity before moving to the next image.

## Reference sheet sections
- Adam — Clean / Identity: canonical face, hair, build and pristine wardrobe.
- Adam — Partial Degradation: same character with increasingly weathered robes, dust and mild grime.
- Adam — Heavy Degradation: deepest-stage wardrobe with distressed linen, ash and exhaustion.
- Adam — Expressions: emotional continuity guide.
- Archon Rulers: canonical ruler design language.
- Archon Hands: canonical symbolic restraining-force design language.

## Core continuity rule
Adam is an original fictional male character. Keep him recognizably identical from image to image. Do not turn him into an exact depiction of any real person.
